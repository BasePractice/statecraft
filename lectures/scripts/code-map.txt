# Какой файл практикума какому листингу лекции соответствует.
#
# Формат:  <путь от корня репозитория>  <путь от корня репозитория>
#          источник (practices/…)       копия (lectures/src/…/code/…)
#
# Копия нужна потому, что typst читает файлы только из своего --root
# (каталога lectures/). Скрипт sync-code.sh поддерживает копии в актуальном
# состоянии, а с ключом --check проверяет, что они не разошлись, — эта же
# проверка стоит в CI.
#
# Чего здесь намеренно нет:
#   practices/08-fsm-control-pneumo/generated/*.log — журнал сборки модели,
#   в лекцию не попадает. Прежде здесь же значились *.inc: они были в CP1251,
#   а копии в лекции — в UTF-8, и побайтовое сравнение не работало. С
#   18.08.2026 оригиналы тоже в UTF-8, и файлы синхронизируются как все;
#   (раньше здесь значился lectures/src/12-takt/code/driver.c как «написанный
#   для лекции» — на деле это копия practices/12-takt/main.c, и она успела
#   разойтись с оригиналом; теперь синхронизируется наравне с остальными).
