# practices — практическая часть курса

Примеры кода к лекциям и практические проекты. Собирается вместе с лекциями
одной командой из корня репозитория:

```bash
cmake -S . -B build && cmake --build build -j
ctest --test-dir build --output-on-failure
```

## Как названы каталоги

`<номер лекции>-<название>` в kebab-case: каталог сразу говорит, к какой
лекции относится практика. Номера лекций берутся из реестра
`lectures/course.typ`, поэтому у одной лекции может быть несколько практик.

| Каталог | Лекция | Что показывает |
|---|---|---|
| `02-fsm-delay` | 2 | автомат «задержка» в модели Мили + модель SimInTech |
| `03-control-program` | 3, 7, 8 | прикладная управляющая программа: датчики, движок, эмуляция |
| `06-regular-expression` | 6 | учебный движок регулярных выражений |
| `06-lexical-analyze` | 6 | лексический анализатор математических выражений |
| `07-simple-program` | 7 | контрпример: вложенные `switch`/`if` вместо автомата |
| `07-fsm-insert-element` | 7 | автомат поиска вставки в последовательности |
| `08-fsm-control-pneumo` | 8 | циклограмма пневмоцилиндров, кодогенерация SimInTech |
| `09-promela` | 9 | десять моделей Promela для SPIN |
| `10-turing-machine` | 10 | интерпретатор машины Тьюринга |
| `11-takt` | 11 | модели на языке Takt и порождение кода |

Служебные каталоги:

| Каталог | Что это |
|---|---|
| `common/` | общий исходный код: `base_types.h`, `base_macro.h`, точка входа тестов, `network/`, заголовок Catch2 |
| `resources/` | сторонние ресурсы, не являющиеся исходным кодом курса: сборки SPIN под Windows |

## Требования к коду

Весь код курса — ISO C90 без расширений и без предупреждений
(`cmake/StatecraftStrictC.cmake`). Оформление проверяется скриптом
`scripts/check-style.sh` по документу `_1.CodeStyle/-1.CodeStyle.md`.

Два документированных исключения:

- тесты пишутся на C++11 (Catch2) — студент C++-код не сдаёт;
- `11-takt`: компилятор `taktc` порождает C99, и драйвер обязан включить
  порождённый заголовок.

## Что не собирается CMake
